How to install

This app isn’t on Google Play, so Android asks you to allow the install. That warning is normal for apps downloaded outside the store.

  1. Download the file. Tap “Download for Android” on your phone. If the browser warns that this file type can be harmful, choose to keep it.
  2. Open it. Find the file in your notifications or the Downloads app and tap it.
  3. Allow the install. If Android says installs from this source are blocked, tap Settings, turn on “Allow from this source,” then go back and tap Install.
  4. Open the app. Tap Open, or find Bunco Bunch in your app list.
Updating: download the newest file and install it over the old one.
